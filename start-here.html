Fictional example · a small backyard flock

Meet Ginger, Dot and Poppy.

1. Give each bird an identity

Add Ginger with code G01, Dot with D02, and Poppy with P03. A name, a code, or both will work. Photos help you recognise them.

What you will have

Three separate bird records. Breed and hatch date can be added later; you do not need every detail to get started.

2. Record what you observe

If Ginger is dominant over Dot, record that link. Add a best-friend link for birds that often stay together.

What you will have

A flock map based on your observations. Best friends and dominance are separate relationships; the app does not infer behaviour from a photograph.

3. Add today’s eggs

Record four collected eggs. Tomorrow, save zero if you checked and collected none. Leave a day blank if you did not record it.

What you will have

A dated egg history and a chart that distinguishes zero from missing data. Egg CSV export is free.

Fictional example · breeding records

Follow one hatch from plan to results.

A keeper wants to document an egg-colour breeding project. The example below illustrates the records; it makes no prediction about inherited traits.

  1. Choose a goal and parents. In Breeding Projects, write the goal in plain language. Select birds by name or code; leave advanced measurements closed until useful.
  2. Set 12 chicken eggs. Start a linked hatch. Check the suggested hatch date and reminders. The countdown shows the next stage.
  3. Record care when it happens. Tick an optional candling check if performed. Add a note or photo only if useful. Prepare for hatching and stop turning according to the species, dates and care routine you are using.
  4. Record eight hatched chicks. The linked chick batch retains its connection to the hatch and project. Record the result even if it differs from the plan.
  5. Keep evidence as chicks grow. Add stage photos and observations. Later identify individual birds and record which you selected for the next generation.
  6. Review the project report. Bring stages, observations and photographs together. Archive a finished project to clear the active list.

For an organiser-issued store code

Your event preview, on phone and web.

Linked web access arrives with the next app update. Existing store products and codes are used. Campaign eligibility and store redemption rules still apply.

  1. Redeem the supplied code through Google Play or the App Store on your phone.
  2. In the updated app, sign in under Settings → Plus, cloud & web access, then choose Restore purchases.
  3. Once the purchase is verified and linked, sign in to the web app with the same email. Link your phone’s flock records when ready.
  4. Check the expiry shown by the app. Web access ends with the original 30-day preview; signing in or reinstalling does not restart or extend it.

No automatic paid subscription starts at the end. One-time purchases remain yours. Retained cloud backups can still be downloaded after access expires, subject to the normal retention limits.
